一.安装步骤：
1.需要找到VMware虚拟机和乌班图20.04的安装包进行安装
2.安装成功VMware虚拟机后要在里面创建Linux系统的虚拟机
3.在Linux系统的基础上将乌班图20.04映像文件安装进去
4.在以上安装完成以后就可以进行ROS Noetic的安装
5.接着就可以在终端通过指令进行对小海龟的操控
二.安装过程中遇到的问题：
1.在一开始发现乌班图版本下载错误，下载的版本太高无法安装ROS Noetic
2.多次安装ROS Noetic失败。这里向豆包请教了一下，发现是原来的ros源失效，更换了清华镜像源，删掉了原来的，解决了
3.终端中输入roscore命令不存在。后面在网上搜寻，发现是没有配置环境变量# www# www
